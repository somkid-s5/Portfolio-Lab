# Icon sources

Service icons embedded in solution.svg are from the official Google Cloud legacy console icon set (Compute Engine, Cloud Load Balancing, Virtual Private Cloud, Cloud Shell).

- Official library: https://cloud.google.com/icons
- Download: https://services.google.com/fh/files/misc/google-cloud-legacy-icons.zip
- Retrieved: 2026-10-21

Original icon geometry and colors are preserved. CSS class fills are inlined to avoid collisions when multiple icons are embedded in one SVG. Google Cloud product icons remain the property of Google.
