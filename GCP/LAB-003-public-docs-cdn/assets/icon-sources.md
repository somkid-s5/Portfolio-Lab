# Icon sources

Cloud Load Balancing, Cloud CDN and Cloud Storage glyphs are embedded from the official Google Cloud legacy icon library.

- Official source: https://cloud.google.com/icons
- ZIP: https://services.google.com/fh/files/misc/google-cloud-legacy-icons.zip
- Retrieved: 2026-10-22

Original icon geometry and colors are preserved. CSS fills are inlined and IDs removed to avoid cross-icon collisions. Icons remain Google property. DNS/certificate/client objects are generic labeled representations: the lab uses an owned DNS provider and a Compute-managed certificate, not Cloud DNS or Certificate Manager. No VPC/VM icon is present because neither is provisioned.

The release-flow figure is a process diagram, not a provider service map.
