# Icon sources

Service icons embedded in solution.svg are from the official Google Cloud legacy console icon set (Compute Engine, Cloud Load Balancing, Virtual Private Cloud, Cloud Shell, Cloud DNS, Cloud NAT and Cloud Router).

- Official library: https://cloud.google.com/icons
- Download: https://services.google.com/fh/files/misc/google-cloud-legacy-icons.zip
- Retrieved: 2026-10-22

Original icon geometry and colors are preserved. CSS class fills are inlined to avoid collisions when multiple icons are embedded in one SVG. Google Cloud product icons remain the property of Google.

The database uses the Compute Engine icon because PostgreSQL is self-managed on a VM, not Cloud SQL. The package-mirror symbol is generic, not a vendor service icon. Icons are embedded without remote dependencies; original colors/geometry are preserved.
